# ARIKARTECH — High-Converting Affiliate UX & Product Funnel

## 1. 3-Second Cognitive Clarity Rule
Every product page is designed to pass the 3-second comprehension threshold:
1. **Clear Identity**: Verified Brand + Model + Canonical Name.
2. **Immediate Best Value**: Highlighted "Best Price We Found" card with emerald accents.
3. **Frictionless Action**: Prominent "BUY AT BEST PRICE" CTA button.
4. **Honest Freshness**: Transparent timestamp ("Price checked 18 minutes ago").

---

## 2. Decision Friction Elimination
- **No Deceptive Scarcity**: Zero fake countdown timers, fake stock counters, or false discount banners.
- **Clear Retailer Distinction**: Verified retailer logos, shipping cost disclosures, and condition indicators (New / Refurbished).
- **Mobile-First Touch Targets**: 48px+ minimum touch targets for affiliate redirect buttons on mobile viewports.
- **Fast First Meaningful Paint**: Server-rendered HTML delivers pricing data with sub-100ms TTFB.
